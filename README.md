Nike Air Jordan 2025 - Projeto de Interface de E-commerce
Este repositório contém o código-fonte de uma interface de e-commerce para a linha de tênis Nike Air Jordan 2025. O projeto foi desenvolvido com foco em design responsivo e interatividade, utilizando HTML, CSS e JavaScript. A interface simula uma página de produto, onde os usuários podem visualizar diferentes modelos de tênis, interagir com um slider de imagens e selecionar opções de cores.

Estrutura do Projeto
1. Header (Cabeçalho)
Logo da Nike: Exibe o logo da Nike no canto superior esquerdo.

Menu de Navegação: Contém links para as seções "Início", "Shop", "Sobre Nós" e "Contatos".

Botões de Login: Dois botões estão disponíveis para "Cadastre-se" e "Entrar", permitindo que os usuários acessem suas contas ou criem uma nova.

2. Slider de Imagens
Slides de Cores: O slider exibe quatro modelos de tênis em diferentes cores (vermelho, cinza, marrom e verde). Cada slide contém:

Texto "NIKE": Repetido duas vezes para efeito visual.

Imagem do Tênis: Uma imagem principal do tênis na cor correspondente.

Interatividade: O slider permite a navegação entre os slides, destacando o slide ativo.

3. Seção Inferior
Texto Descritivo: Exibe uma imagem com texto estilizado e o nome do produto "NIKE AIR JORDAN 2025".

Miniaturas de Cores: Na parte direita, há miniaturas dos tênis em diferentes cores. O usuário pode clicar em uma miniatura para alterar a cor do tênis exibido no slider.

4. JavaScript (Interatividade)
O arquivo nike.js é responsável por:

Controlar a troca de slides no slider.

Atualizar a imagem principal conforme a miniatura selecionada.

Gerenciar a classe active para destacar o slide e a miniatura atuais.

Tecnologias Utilizadas
HTML: Estruturação do conteúdo da página.

CSS: Estilização e design responsivo.

JavaScript: Funcionalidades interativas, como a troca de slides e miniaturas.
